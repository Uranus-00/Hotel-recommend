# 云宿 YUNSU · 著名景点酒店推荐

一个面向中国旅行者的**景点酒店推荐静态网站**。围绕桂林漓江、张家界、杭州西湖、黄山、三亚亚龙湾、丽江古城六大著名景点，精选 18 家周边酒店，提供筛选、搜索、收藏、详情查看与预订意向提交等完整浏览体验。

项目为**纯静态多页面网站**：无需构建、无 npm 依赖，Vue 运行库已本地化，双击 `index.html` 即可运行。

## 功能特性

### 内容与浏览

- **四大独立页面**：首页 / 热门目的地 / 精选酒店 / 服务保障，各自独立成页
- **六大目的地深度解析**：亮点标签、最佳季节、建议行程天数、周边酒店数量
- **18 家精选酒店**：覆盖 ¥680 - ¥3680 不同预算，4 星级 5 家、5 星级 13 家
- **酒店详情弹窗**：大图、星级条、设施网格、地址电话、价格卡与预订入口

### 筛选与检索

- 按目的地筛选（标签胶囊，一键切换）
- 关键词搜索，匹配**酒店名 / 景点名 / 地区 / 标签**四类字段
- 价格区间筛选（4 档）
- 星级筛选（五星级 / 四星级）
- 四种排序：综合推荐、价格升序、价格降序、评分最高
- 筛选条件实时联动，结果条显示当前条件，一键清除

### 交互

- **收藏**：localStorage 持久化，头部计数徽标，支持「只看收藏」
- **跨页传参**：首页搜索、目的地按钮、精选卡片均可携带条件跳转到酒店页
- **滚动显现动画**：卡片随滚动进入视口淡入上浮（IntersectionObserver）
- **响应式布局**：桌面 / 平板 / 手机三档断点，移动端折叠为汉堡菜单
- **无障碍与降级**：语义化标签、`aria-label`、键盘 `Esc` 关闭弹窗、无 JS 时链接仍可用
- **减少动效**：尊重系统 `prefers-reduced-motion` 设置

## 快速开始

### 方式一：直接打开（最简单）

双击 `index.html`，浏览器会以 `file://` 协议打开。所有功能均可用。

### 方式二：本地服务器（推荐）

部分浏览器对 `file://` 下的资源加载有限制，起一个静态服务器体验更完整：

```bash
# 在项目根目录执行
python -m http.server 8123
# 然后访问 http://127.0.0.1:8123/index.html
```

或用 Node：

```bash
npx serve .
```

> **注意**：请保持目录结构不变。所有资源引用均为相对路径，移动 `css/`、`js/`、`img/` 任一目录都会导致样式或图片失效。

## 页面跳转与参数传递

页面之间通过 URL 查询参数传递筛选条件，由 `app.js` 的 `initFromQuery()` 在挂载时读取并自动应用。

| 参数 | 作用 | 示例 |
| --- | --- | --- |
| `dest` | 按目的地筛选 | `hotels.html?dest=guilin` |
| `q` | 关键词搜索 | `hotels.html?q=阳朔悦榕庄` |
| `fav` | 只看收藏 | `hotels.html?fav=1` |

**已有的跳转链路**：

- 首页首屏搜索框 → `hotels.html?q=关键词`
- 首页编辑精选卡片 → `hotels.html?q=酒店名`
- 首页三大板块入口 → 对应页面
- 目的地页「查看该地酒店」→ `hotels.html?dest=目的地ID`
- 页脚目的地链接 → `hotels.html?dest=目的地ID`
- 顶栏收藏按钮 → `hotels.html?fav=1`

**跳转实现**：`navTo()` 方法直接赋值 `window.location.href`，不做全屏过渡；按住 `Ctrl` / `Cmd` / `Shift` 或中键点击时交还浏览器，支持新标签页打开。

## 数据维护指南

所有内容数据集中在 **`js/data.js`**，与页面结构完全分离，改数据不需要动 HTML。

### 新增一家酒店

在 `HOTELS` 数组中追加对象：

```js
{
  id: 19,                              // 唯一数字 ID，不可重复
  dest: 'guilin',                      // 归属目的地，必须是 DESTINATIONS 中已存在的 id
  name: '酒店名称',
  img: 'img/hotel-guilin-4.jpg',       // 相对项目根目录的路径
  price: 1280,                         // 每晚起价（数字，用于筛选与排序）
  oldPrice: 1580,                      // 门市价，可省略
  rating: 4.8,                         // 评分 0 - 5，用于排序与星级条
  reviews: 3260,                       // 点评数
  stars: 5,                            // 4 或 5，用于星级筛选
  featured: true,                      // 是否显示「小编精选」徽标，可省略
  tags: ['漓江景观', '室外泳池'],        // 标签，卡片上最多显示 3 个
  distance: '距漓江 0.8 km',
  address: '广西桂林市滨江路 111 号',
  phone: '0773-8888 888',
  facilities: ['免费 WiFi', '室外泳池'], // 详情弹窗的设施网格
  desc: '酒店介绍文案……'
}
```

### 新增一个目的地

在 `DESTINATIONS` 数组中追加：

```js
{
  id: 'chengdu',                       // 唯一字符串 ID，会被酒店对象的 dest 引用
  name: '成都青城山',
  region: '四川 · 成都',
  tag: '道教名山 · 避暑胜地',
  img: 'img/spot-chengdu.jpg',
  intro: '一句话简介……',
  highlights: ['青城前山', '都江堰'],    // 亮点标签
  bestSeason: '4 - 10 月',
  duration: '建议 2 - 3 天'
}
```

### 修改常见问题

编辑 `FAQS` 数组，每项为 `{ q: '问题', a: '回答' }`。服务保障页会自动渲染为手风琴。

> **提示**：改动数据后，浏览器可能需要 `Ctrl + F5` 强制刷新以绕过缓存。

## 样式定制

全站配色、圆角、阴影、容器宽度集中在 `css/style.css` 顶部的 `:root` 中，改这里即可整体换肤：

```css
:root {
  --brand:      #0f766e;   /* 主色（深青绿） */
  --brand-2:    #14b8a6;   /* 主色亮阶，用于渐变起点 */
  --accent:     #f59e0b;   /* 强调色（琥珀金） */
  --ink:        #0f172a;   /* 正文主色 */
  --muted:      #64748b;   /* 次要文字 */
  --bg:         #f7f9fb;   /* 页面底色 */
  --radius:     20px;      /* 大圆角（卡片、区块） */
  --container:  1200px;    /* 内容最大宽度 */
}
```

**响应式断点**：

| 断点 | 生效变化 |
| --- | --- |
| `≤ 1080px` | 酒店网格 3 列 → 2 列，页脚 4 列 → 2 列 |
| `≤ 860px` | 导航折叠为汉堡菜单，弹窗正文改单列，搜索条竖排 |
| `≤ 640px` | 全部网格改单列，缩小内边距 |

**品牌标识**：`.brand-mark` 尺寸固定为 40×40，背景引用 `img/logo-mark.png`（由 `云宿logo.png` 裁出的图形部分，去掉了原图自带的「云宿」字样，避免与右侧文字重复）。
